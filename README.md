# [PROJECT_NAME]

Harmonized MODIS + VIIRS burning activity calendar. NASA Space Apps Challenge 2026, "Harmonization of MODIS and VIIRS Hot Spots".

- `pipeline/`: Python data pipeline (FIRMS download, cleaning, harmonization, validation, JSON export).
- `web/`: Next.js web app (globe, calendar, AI assistant). Reads the JSON files in `web/public/data/`.
- `docs/PROJECT_SPEC.md`: project specification and data contract.

## AI usage
AI coding assistants were used to generate code. The method and design were decided by the team.
